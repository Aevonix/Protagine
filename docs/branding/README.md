# PacoMind artwork

These are the approved Stepped logo files from the
[Aevonix Research press kit](https://aevonix.com/branding), copied without changes.

| File | Use |
| --- | --- |
| `pacomind-primary-dark.svg` | Light lettering and spectrum accents for a dark background. |
| `pacomind-primary-light.svg` | Graphite lettering and darker accents for a light background. |
| `pacomind-avatar.png` | 512 × 512 avatar with a graphite background. |

The SVG lettering is outlined and does not require a font. The repository README
selects the appropriate artwork for the reader's light or dark appearance.

Keep the names, proportions and colors intact. Do not retype the wordmark or add
scanlines, glow or other effects through the logo. The
[brand guide](https://aevonix.com/branding) covers clear space, minimum sizes,
colors and typography. The
[PacoMind logo kit](https://aevonix.com/brand/current/pacomind-logos.zip) includes
additional layouts and formats.
