# Protagine artwork

**Protagine** stands for **Proto AGI Engine**. These files are copied unchanged
from the [Aevonix Research brand guide and press kit](https://aevonix.com/branding).
The Engine symbol and stencil wordmark share Aevonix Research's palette.

| Files | Use |
| --- | --- |
| `protagine-primary-{dark,light}.{svg,png}` | Full logo with the Proto AGI Engine descriptor. PNGs are 1600 pixels wide. |
| `protagine-compact-{dark,light}.svg` | Symbol and wordmark without the descriptor. |
| `protagine-mark-{dark,light,black,white}.svg` | Standalone symbol in color or one ink. |
| `protagine-avatar.png` | 512 × 512 avatar on graphite. |
| [protagine-logos.zip](protagine-logos.zip) | Full SVG, PNG and PDF logo set, guide and palette files. |

`dark` means light inks for a dark background; `light` supplies graphite
lettering and darker accents for a light background. SVG lettering is outlined
and does not require a font. The repository README selects the appropriate
artwork for the reader's appearance.

## Color and layout

| Color | sRGB HEX |
| --- | --- |
| Graphite | `#151615` |
| Cream | `#F3E5CD` |
| Amber | `#EEB07E` |
| Coral | `#D99288` |
| Teal | `#A9D5CE` |
| Muted cream | `#C0B4A0` |

Use the supplied light-background variants; their darker accent inks are
already applied. Keep the artwork's proportions and colors intact. Do not
retype the wordmark or add scanlines, glow or other effects through the logo.

Recommended minimum widths are **320 CSS pixels** for the primary logo,
**200 CSS pixels** for the compact logo and **24 CSS pixels** for the symbol.
Keep at least one quarter of the visible symbol's height clear around the
entire logo, including its descriptor. The full guide covers typography,
print use, additional colors and press copy.

## Usage

Earlier PacoMind assets remain in this directory for compatibility; use the
Protagine files for new artwork. A software repository's open source license
does not itself grant a license to the brand assets. This kit does not
introduce a new trademark or software license for the logos.
